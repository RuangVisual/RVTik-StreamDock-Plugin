## Overview

**RVTik StreamDock Plugin** is the official StreamDock integration for RVTik Stream Pro, designed to simplify live streaming workflows through dedicated physical controls.

Control your dashboard, music playback, Quick Panel, and supported live streaming features directly from your StreamDock device without constantly switching between application windows.

Designed for TikTok LIVE creators, streamers, and content creators who want a faster and more convenient streaming experience.

## ✨ Key Features

### Dashboard Control

- Open and activate the RVTik Dashboard.
- Quick access to RVTik control panels.
- Improved window activation and restoration.
- Reduce unnecessary application switching during live streams.

### Quick Panel Integration

- Access supported RVTik Quick Panel actions.
- Real-time control status synchronization.
- Convenient shortcuts for live streaming operations.
- Seamless integration with the existing RVTik Quick Panel.

### Music Control

- Play and pause music.
- Skip tracks.
- Access the Music Control panel.
- Real-time Now Playing information.
- Scrolling track information.
- Spotify and YouTube playback integration through RVTik.
- Music playback status synchronization.

### Connection & Authorization

- Automatic local connection to RVTik Stream Pro.
- One-time authorization.
- Real-time connection status.
- Authorized control execution.
- No repeated approval for every individual action after successful authorization.

### User Experience

- Official RVTik branding and icons.
- Dedicated Windows installer.
- Simple installation and configuration.
- Customizable StreamDock button layouts.
- Responsive physical button controls.

## 🚀 Installation Guide

### Step 1 — Install StreamDock

Make sure the official StreamDock desktop application is installed on your Windows PC and your device is connected.

### Step 2 — Install RVTik StreamDock Plugin

1. Download the latest plugin installer.
2. Close the StreamDock application.
3. Run the RVTik StreamDock Plugin Setup.
4. Follow the installation instructions.
5. Complete the installation.

### Step 3 — Restart StreamDock

Launch the StreamDock desktop application again to load the installed plugin.

### Step 4 — Configure Your Device

1. Launch RVTik Stream Pro.
2. Open the StreamDock application.
3. Locate the RVTik plugin in the action list.
4. Drag your preferred RVTik actions onto the device layout.
5. Customize your button arrangement as needed.

### Step 5 — Authorize Connection

Complete the initial authorization when prompted by RVTik Stream Pro.

Once authorized, supported StreamDock actions can communicate with RVTik without requiring individual approval for every button press.

## 🛠️ Troubleshooting

### RVTik Plugin Does Not Appear

- Make sure the plugin installation was completed successfully.
- Restart the StreamDock application.
- Verify that your StreamDock software is up to date.

### Plugin Shows Disconnected

- Make sure RVTik Stream Pro is running.
- Verify that both applications are running on the same Windows PC.
- Check the connection and authorization status.
- Restart both applications if necessary.

### Buttons Do Not Respond

- Make sure the initial authorization has been completed.
- Check whether the selected action is supported by your installed RVTik version.
- Verify the StreamDock connection.
- Remove and re-add the affected action if necessary.

### Music Information Does Not Appear

- Make sure the RVTik Music feature is active.
- Verify that a supported music source is configured.
- Start playing a track through RVTik.
- Check the plugin connection status.

## 🔒 Security & Privacy

RVTik StreamDock Plugin is designed to communicate locally with RVTik Stream Pro.

- Authorized communication between the plugin and RVTik.
- Protected access to supported control actions.
- One-time authorization to simplify trusted device access.
- No separate RVTik account credentials required inside the StreamDock plugin.
- No direct access to the user's RVTik license database.

The plugin does not replace or bypass the existing RVTik authorization and security mechanisms.
